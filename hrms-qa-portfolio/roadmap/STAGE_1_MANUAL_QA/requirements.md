# Sample authentication requirements
These are learning requirements, not official product specifications.
| ID | Requirement | Acceptance criteria |
|---|---|---|
| AUTH-001 | Login page loads | Username, password and Login controls are visible |
| AUTH-002 | Invalid login rejected | Dashboard does not open |
| AUTH-003 | Password masked | Typed password is obscured |
| AUTH-004 | Keyboard navigation | Fields and submit button can be accessed with keyboard |
| AUTH-005 | Protected route guarded | Logged-out user cannot access protected dashboard |
